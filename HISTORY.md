# History and public-copy disclosure

This preview is derived from development `master` at
`ce64ecd0fe8e206b5a4758ff61139a282056e22b`. The private development repository
remains the authoritative source. This export does not change its history.

## What was preserved

All **83 commits reachable from that source revision**, including **15 merge
commits**, are represented in their original parent relationships. Original
author and committer names and timestamp instants are retained. The history
starts on July 13, 2025, and ends at the source revision dated October 26, 2026.
Commits made empty by privacy exclusions are retained, so this is not a new
single-commit snapshot or a fabricated sequence of development milestones.

The source was retrieved through the GitHub connector. All 417 distinct source
blobs were checked against their Git object SHA. Author/committer date offsets
are normalized to UTC because the source API exposes UTC instants. Original
signatures are not carried over: a signature on an original commit cannot
validate a modified public copy.

The [commit map](provenance/history-map.csv) relates the original source commits
to their public counterparts. Original SHA references inside scientific
protocols still identify the private development source, not this rewritten
copy. Those protocols and their scientific code/assets have not been amended
for this portfolio release.

## What was removed or redacted

The exclusions apply at **every commit**, not just at the current tip:

- Personal commit email addresses and workstation addresses are replaced with
  the owner's verified GitHub noreply identity or a clearly noncontact
  `contributors.invalid` alias. Author names, coauthor credit, Copilot credit,
  and existing public bot identities are preserved.
- Private research planning and mentor-correspondence material is not included.
  The standalone mentor feedback attachment was never part of this Git history.
- Standalone spatial execution reports, private operational checkpoints, transition bindings, retained execution
  outputs, evidence-archive identifiers, and internal agent instructions are
  excluded. Cohort-specific recovery adapters and their tests are omitted as well. Generic coordination source and its tests remain inspectable.
- Private export-preparation tools, their embedded old release maps, and their dedicated CI workflow are excluded to avoid publishing internal release records.
- Editor configuration, filesystem metadata, and a generated simulation export
  are excluded. The application can produce new exports locally.
- Concrete private execution locations in `operations/workflow/REPORTING.md`
  are replaced with generic placeholders.

The source commit messages retain their historical meaning, with private
contact details redacted. Historical plans, claims, test reports, and research
status statements are not recertified as current facts by this publication.
Historical references to excluded documents may therefore be unavailable.
The public README and reviewer guide define the preview's current scope.

Filtering changes commit hashes. This is a **sanitized derivative history**,
not an exact mirror. Only the ancestry reachable from the selected master
revision is included; unrelated branches, pull-request discussions, issue
threads, Actions logs/artifacts, repository settings, and secrets are not
part of this export.

## New preview work

The final release-preparation commit adds the reviewer-facing README,
architecture guide, an engineering-focused research-directory guide, this disclosure, provenance map, verification notes, and
a bounded synthetic demonstration wrapper. It is dated when the preview was
prepared, not backdated into project development. That work was assisted by
ChatGPT/Codex and does not alter the underlying simulator, research protocols,
model parameters, or experimental results.

The private review found no obvious credentials or private biological datasets
in the inspected ancestry. This is a scoped review, not a guarantee against
every possible secret or a clearance of the original repository's ancillary
surfaces. Future source revisions require a fresh review before export.
